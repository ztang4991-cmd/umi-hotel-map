# UMI 酒店地图项目

> 婚礼管家专用的客户需求匹配工作台。30 秒内根据客户预算、区域、桌数、风格，从 80 家合作酒店中定位匹配候选。

## 🚀 快速开始

### 给管家用（最常见）
1. 双击 `tools/UMI酒店地图_V2.html` 用浏览器打开（手机端优先）
2. 顶部或抽屉里勾选客户需求（区域 / 餐标 / 桌数 / 风格）
3. 地图自动高亮匹配酒店
4. 点击酒店看详情卡片；如果酒店数据里配置了 `videoUrl`，详情里会直接播放带看视频

### 给新人管家培训
打开 `docs/UMI酒店地图_管家培训手册.docx`，30 分钟读完 + 完成 5 道考核题，即可独立使用工具。

### 给开发者 / Claude Code
请先读 **`CLAUDE.md`**——里面有完整的项目背景、数据结构、决策记录、待办路线图。

重新生成 V2 地图：

```bash
node scripts/build_v2.js
```

## 🎯 核心数据

- **80 家成都合作酒店**（覆盖 12 个区域）
- **2 个合作渠道**：时光在线（约 75 家）、昌森（约 10 家），其中 5 家两边都代理
- **6 大风格分类**：酒店宴会厅 / 中式 / 西式 / 户外草坪 / 独栋会所 / 园林度假
- **4 档餐标 + 4 档桌数**

## ⚙️ 技术栈

- 数据：Excel
- 地图：Leaflet + 高德地图
- 坐标系：GCJ-02（火星坐标系）
- 前端：纯 HTML + 原生 JS（零构建依赖）
- 地理编码：高德开放平台 API

## 🤝 数据回流机制

管家在工作中获得的酒店信息（餐标、桌数、新酒店等）通过企业微信群 **"UMI 酒店数据更新群"** 回流，运营每周一次汇总更新。

具体格式见培训手册第九章。

## 📝 维护说明

- **新增酒店**：见 `CLAUDE.md` "任务 A"
- **回填数据**：见 `CLAUDE.md` "任务 B"
- **重新生成地图**：见 `CLAUDE.md` "任务 C"

## ⚠️ 重要提醒

1. **高德 API Key 不要硬编码到公开代码**，请用 `.env` 文件管理
2. **所有坐标统一 GCJ-02**，禁止混入 WGS-84（谷歌坐标系）会导致地图偏移 50-500 米
3. **修改主数据库后必须重新生成地图 HTML**，否则地图显示的还是旧数据
